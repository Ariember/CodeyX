# CodeyX v1.3.5 · Windows 启动兼容与交互优化

本次更新修复 Windows 启动进程交接与第三方线路预热兼容问题，改进模型搜索和扩展批量管理，并减少界面与会话状态处理的重复开销。

## 本次亮点

### Windows 启动兼容

修复启动入口转交桌面进程后被误判退出的问题，保持退出监测、重启与进程清理一致。

### 模型搜索与扩展选择

官方模型列表支持搜索和清空条件；MCP 与 Skill 管理支持跨页累加选择及取消本页选择，最多同时选择 100 项。

## 优化与修复

- 修复 WebSocket 预热回退 HTTP 时意外触发生成的问题，保留后续请求所需的会话历史。
- 设置菜单支持方向键、Home 和 End 导航。
- 减少会话统计、模型菜单、提示词优化、配置与扩展清单读取的重复处理。
- 减少流式响应转发与日志采样中的重复复制。
- 关闭设置后减少宿主页面的样式计算，简化插件导入失败后的重试入口。

## 升级须知

- Windows 仅支持原生后端，使用前请在 Codex 设置中关闭 WSL 选项。
- 安装前请结束正在进行的 Codex 任务；下载与安装仍分别确认。
- macOS arm64 提供未签名应用包。
