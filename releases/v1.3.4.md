# CodeyX v1.3.4 · 文件操作与工具调用兼容改进

本次更新扩展 FastCtx 文件操作，修复上下文压缩后的工具调用与多代理状态识别，并减少页面增强的重复检查和布局计算。

## 本次亮点

### FastCtx 文件操作

内置 FastCtx 支持新建、移动和删除文件。新建与移动不覆盖已有路径，删除默认预览，仅处理明确指定的文件、空目录和符号链接。

### 会话工具恢复

修复上下文压缩后工具声明丢失导致的调用失败，并改进多代理任务完成、异常和中止状态的识别。

## 优化与修复

- 减少侧栏、模型菜单、会话统计和提示词优化按钮的重复扫描、布局读取与状态写入。
- 改进额度提示的关闭交互与显示状态同步。
- 修复新版 Codex 下宠物自动预热抑制与运行时优化未生效的问题，保留语音浮窗按需创建。
- 系统优化诊断显示待确认、异常和状态未知的项目及具体原因。

## 升级须知

- FastCtx 新建、移动和删除的改动不纳入对话 Git 归集。
- Windows 仅支持原生后端，使用前请在 Codex 设置中关闭 WSL 选项。
- 安装前请结束正在进行的 Codex 任务；下载与安装仍分别确认。
- macOS arm64 提供未签名应用包。
