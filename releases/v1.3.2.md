# CodeyX v1.3.2 · 会话兼容与交互性能改进

本次更新改进第三方线路的多代理协作与工具调用兼容性，减少界面重复检查，并改善启动连接速度。

## 本次亮点

### 第三方线路会话兼容

修复代理任务消息回放时的角色转换，保留会话恢复和连接回退后的任务语义；改进工具调用历史的转换，避免部分上游将结尾的助手消息误判为续写前缀而拒绝请求。

### 更轻量的界面交互

减少菜单和侧栏变化触发的 Git 状态查询与输入框布局读取，优化会话统计和提示词优化按钮的观察与刷新，保留会话切换、按钮重挂和定时刷新行为。

## 优化与修复

- 启动时并行探测本机调试地址，避免无响应地址拖慢可用连接的发现。
- 改进额度提示的关闭交互，保持提示状态与页面变化同步。
- 简化网络配置，客户端与线路请求统一沿用系统网络环境。

## 升级须知

- 本版本移除 Codex 启动代理和独立线路代理配置；需要代理时请配置系统网络环境。
- Windows 仅支持原生后端，使用前请在 Codex 设置中关闭 WSL 选项。
- 安装前请结束正在进行的 Codex 任务；下载与安装仍分别确认。
- macOS arm64 提供未签名应用包。
