# CodeyX v1.3.3 · 宠物精简与运行诊断修复

本次更新修复新版 Codex 下的宠物预热抑制与运行时优化，并让系统优化诊断显示待确认和异常项目。

## 优化与修复

- 修复宠物入口已精简但自动预热抑制未生效的问题，保留语音浮窗按需创建。
- 恢复 CPU 采样、交互心跳和周期诊断的运行时优化。
- 系统优化诊断列出待确认、异常和状态未知的功能，显示名称与具体原因。

## 升级须知

- Windows 仅支持原生后端，使用前请在 Codex 设置中关闭 WSL 选项。
- 安装前请结束正在进行的 Codex 任务；下载与安装仍分别确认。
- macOS arm64 提供未签名应用包。
