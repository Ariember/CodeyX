# CodeyX v1.3.0 · Windows 统一使用原生后端

本次更新减少界面交互与滚动开销，改进请求传输和会话用量统计，并将 Windows 运行环境统一为原生后端。

## 本次亮点

### Windows 统一使用原生后端

本版本移除 WSL 后端支持。启动时会检查 Codex 的后端设置，启用 WSL 时提示关闭后重试，不自动改写用户设置。

### 更流畅的桌面交互

减少模型菜单、输入框和会话变化触发的重复检查与布局计算，改善点击、输入和滚动响应，保留侧栏展开与标题栏拖动行为。

### 官方请求传输压缩

发往 ChatGPT Codex 官方对话入口的 HTTP 请求支持正文压缩，减少传输数据量；大请求在后台压缩，压缩失败时使用原文发送。

## 优化与修复

- 改进子代理任务完成后的 Token 用量归属，避免重复或冲突数据造成统计偏差。
- 修复会话切换、空闲和任务结束后的统计刷新问题。
- 修复配置内容未变化或恢复原值时仍显示未保存的问题。

## 升级须知

- Windows 仅支持原生后端；使用前请在 Codex 设置中关闭 WSL 选项，CodeyX 不会自动改写该设置。
- 安装前请结束正在进行的 Codex 任务；下载与安装仍分别确认。
- 请求正文压缩不改变上下文内容或 Token 用量，不代表额度增加。
- macOS arm64 提供未签名应用包。
