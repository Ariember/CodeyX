# CodeyX v1.2.5 · 会话自动清理与后台性能优化

本次更新新增按保留天数自动清理本机会话，并减少隐藏窗口中的检测与布局开销。

## 本次亮点

### 会话自动清理

会话管理支持自定义保留天数和时间筛选；确认启用后立即检查，运行期间每小时清理超过期限的本机会话及归档。

## 优化与修复

- 隐藏窗口暂停会话检测与 Git 面板刷新，恢复可见时继续检查。
- 延后读取页面布局，减少界面变化时的同步布局开销。

## 升级须知

- 自动清理默认关闭，按最后更新时间判断；启用后永久删除超过保留期限的本机会话及关联历史缓存，无法撤销，未知更新时间的会话保留。
- 自动清理包含归档，不受当前列表筛选影响；不处理云端会话、项目文件、账号配置和用户另存的备份，部分缓存需重启 Codex 后完成清理。
- 升级前请结束正在进行的 Codex 任务；下载与安装仍分别确认。
- macOS arm64 提供未签名应用包。
